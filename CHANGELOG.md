# Изменения

## 0.5

Неполная сборка: сделано ядро, впереди ещё работа.

Версия на GitHub — `0.5`. В `package.json` она записана как `0.5.0`, потому что
npm требует в поле `version` три части и `0.5` не принимает; расхождения здесь нет,
это одна и та же версия.

Питомец для Web-GUI DeepSeek Harness: спрайт в углу экрана, который показывает,
чем занят агент, и умеет звать, когда нужен ты.

### Два облика

- `main` — обычный кит с лёгкой улыбкой.
- `crazy` — тот же кит с круглыми глазами и широким оскалом.

Каждый облик — полный набор из десяти анимаций и трёх значков, поэтому
переключение мгновенное и не сбивает ни размер, ни состояние. Выбор делается в
меню по правой кнопке и запоминается между запусками.

### Меню по правой кнопке

Отдельным окном, потому что окно питомца ровно в размер спрайта: панель внутри
него была бы обрезана и не приняла бы клики. Сверху стили с отметкой текущего,
снизу — «Выход», который убирает кита с экрана.

### Состояния

| Состояние | Когда |
|---|---|
| покой | агент простаивает |
| покой, вариант с пузырём | изредка вместо обычного покачивания |
| сон | простой дольше трёх минут |
| радость | курсор наведён или по питомцу кликнули |
| думает | агент генерирует ответ |
| **ждёт тебя** | агент заблокирован: разрешение, вопрос или проверка плана |
| взял в руки | питомца перетаскивают |
| отпустил | питомца отпустили |
| готово | работа завершилась: кит рассыпается искрами и превращается в галочку |

«Ждёт тебя» — главное, ради чего это нужно: состояние старше всех остальных, а
значок над головой (`!`, `?` или документ) говорит, чего именно ждут. Галочка
висит, пока её не подтвердят кликом или открытием переписки, и не гаснет по
таймеру.

### Управление

- **Клик** — открыть DSH с последним рабочим чатом и заодно снять галочку.
- **Перетаскивание** — перенести питомца в любое место экрана.
- **Правый клик** — убрать питомца.

### Устройство

- Плагин из двух половин: host (`index.js`) отдаёт состояния по HTTP и запускает
  окно, браузерная (`client.js`) читает три сигнала из UI и складывает их в одно
  состояние.
- Питомец — отдельный процесс Electron: окно без рамки, прозрачное, поверх всех,
  не забирает фокус. Поэтому клик по нему не мешает работать в других окнах.
- Все десять слоёв смонтированы одновременно, переключение — перетекание
  прозрачности с разной длительностью для разных переходов.
- Анимации-события перезапускаются с первого кадра, фоновые петли одной длины
  (2160 мс), чтобы сцена не расходилась.

### Проверки

174 проверки: 47 на браузерной половине, 57 на host, 70 на окне. Плюс генератор
графики сам следит за тем, чтобы кит не вылезал за кадр и чтобы фоновые петли не
разъезжались.
